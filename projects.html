PROJECT PORTFOLIO

Four End-to-End Data Projects

Each project was designed, built and documented independently — spanning Azure, Snowflake, dbt Cloud, BigQuery, Prefect and Power BI — to demonstrate the same production-engineering habits I built up over four years in banking: tested pipelines, clear data models, and dashboards business users can actually trust.

Hospitality EPOS Data Pipeline

An end-to-end enterprise-style data platform processing 50,000 synthetic EPOS transactions across restaurants, pubs and hotels: Python data generation → Azure SQL → Azure Data Factory → Snowflake → dbt Cloud → Power BI DirectQuery. Configured Snowflake Storage Integration with Azure IAM and full RBAC, and built a 3-tier dbt model with window functions powering a 2,000-customer loyalty and CLV forecast — 5 of 5 automated schema tests passing.

Python Azure SQL Azure Data Factory Snowflake dbt Cloud Power BI

UK Data Job Market Intelligence Platform

A fully automated data platform orchestrated with Prefect, ingesting 200+ live UK job listings a day via the Adzuna API into Google BigQuery. A 3-tier dbt transformation layer with SQL-based skills text-mining feeds a Power BI dashboard tracking salary trends and geographic hiring hotspots.

Python Prefect BigQuery dbt Power BI

Retail Banking Customer Attrition Analysis

Analysed 5,000 customer profiles and 62,000+ transaction records to identify behavioural attrition drivers using SQL and Python, delivered through a multi-page Power BI executive dashboard tracking attrition KPIs, regional performance and balance trends.

UK Financial Transactions Data Pipeline

A cloud-native ELT pipeline ingesting live transactional JSON from a public REST API into Google BigQuery using PyArrow for efficient in-memory data handling and GCP IAM for secure service-account credentials, connected to Power BI for reporting.
